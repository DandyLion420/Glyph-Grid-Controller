# Glyph Grid Controller

An Android application for creating, saving, loading and controlling custom patterns on the **Nothing Glyph Matrix**.

Currently being developed and tested on the **Nothing Phone (4a) Pro** using Nothing's Glyph Matrix SDK.

## 🚧 Project Status

**Work in progress.**

The core functionality is working, but the application is still under active development. The interface, features and project structure may change significantly between commits.

## ✨ Current Features

- Interactive Glyph Matrix grid
- Manually create Glyph patterns
- Control Glyph brightness
- Save custom patterns
- Load saved patterns
- Delete saved patterns
- Send patterns to the Nothing Glyph Matrix
- Integration with the Nothing Glyph Matrix SDK

## 🔨 Currently Working On

- UI redesign and cleanup
- Improved Android navigation/inset handling
- Pattern management interface
- General usability improvements

More features are planned as development continues.

## 📱 Development Device

Primary development and testing device:

- Nothing Phone (4a) Pro
- Android 16

## 🛠️ Built With

- Kotlin
- Android Studio
- Gradle
- Nothing Glyph Matrix SDK 2.0

Mobile development/testing is also being explored using **Code on the Go**.

## 💡 Project Goal

Glyph Grid Controller aims to provide a simple visual interface for creating and controlling custom Glyph Matrix patterns without requiring users to manually program individual Glyph sequences.

The long-term goal is to make experimenting with the Glyph Matrix quick, visual and accessible.

## ⚠️ Compatibility

This project is currently designed specifically around Nothing devices that support the **Glyph Matrix**.

Compatibility with other Nothing devices has not yet been tested.

## 📦 Building

This repository is currently intended primarily for development and experimentation.

To build the project:

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect a compatible Nothing device.
5. Build and run the application.

Additional setup instructions will be added as the project develops.
